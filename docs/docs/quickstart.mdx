## Clone the repo

Clone the codebase locally by running the following:

```bash
git clone https://github.com/luminal-ai/luminal
cd luminal
```

## Hello World

Runtime crates own executable examples. Run a small matrix multiplication on
the reference runtime like so:

```bash
cargo run --release -p luminal_reference --example simple
```

The logical graph is built with `luminal`; loading, searching, and executing it
happens entirely inside the reference-runtime crate.

## Run a model with CUDA Lite

With an NVIDIA GPU and CUDA installed, run the full Llama 3 logical model
through CUDA Lite:

```bash
cargo run --release -p luminal_cuda_lite --example llama3 --features device
```
